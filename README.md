# 3D-SOLAR-SYSTEM
 🌌 3D CSS Solar System — Balaji 🚀

I’m excited to share my latest frontend project — a fully animated **3D CSS Solar System Simulation** built using pure **HTML, CSS, and JavaScript**.

This project visually represents the solar system with realistic orbital animations, interactive controls, responsive scaling, and immersive 3D transformations. The entire project is developed in a single-file structure with embedded styling and logic, making it lightweight and easy to explore.

✨ Key Features:
🔹 Pure CSS 3D planet orbit animations
🔹 Interactive 2D / 3D viewing modes
🔹 Dynamic zoom controls
🔹 Responsive design for all screen sizes
🔹 Planet information tooltips
🔹 Realistic orbital speed animations
🔹 Saturn ring effects and moon orbit system
🔹 Embedded textures and smooth transitions
🔹 Modern UI with animated controls panel

🛠 Technologies Used:
• HTML5
• CSS3
• JavaScript
• CSS Keyframe Animations
• Transform & Perspective Effects
• Responsive Media Queries

This project helped me improve my skills in:
✅ Advanced CSS animations
✅ DOM manipulation
✅ 3D transformations
✅ Responsive UI development
✅ Interactive frontend design
✅ Performance optimization in animations
